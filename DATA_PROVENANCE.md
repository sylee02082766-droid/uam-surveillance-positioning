# Public demo data

`filtered_buiding_magok_b_box.txt`: four manually fabricated rectangular obstacles. Columns: string ID, X [m], Y [m], width [m], depth [m], height [m]. No header is used, matching the existing importer.

`mountain_pos_height.txt`: one manually fabricated hill. Columns: label, X [m], Y [m], height [m]. The importer assigns a fixed 200 m radius.

Coordinates were selected for an illustrative scenario in the simulation coordinate system. These records do not describe actual buildings, terrain or a real radio deployment. The original similarly named files were excluded because their upstream GIS provenance and redistribution terms were not established.

All generated results from these inputs must be labeled synthetic demo results.
